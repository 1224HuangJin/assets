# 1224HuangJin/assets

## 项目简介

`assets` 是用户 **@1224HuangJin** 的个人视觉资源集中仓库，用于统一存放和管理所有网络身份头像、表情包/贴图（Stickers/Memes）及其他视觉素材。

## 仓库结构

```
assets/
├── images/
│   ├── icon/          # 个人网络身份头像（多尺寸）
│   │   └── XJH/       # 小号相关头像及图片资源
│   └── stickers/      # 表情包、GIF动图等贴图资源
│       └── files/     # 贴图文件存放目录
├── LICENSE            # 许可证文件
└── README.md          # 本说明文档
```

## 目录说明

### 📁 `images/icon/` — 个人头像库

存放用户 **1224HuangJin** 的主要网络身份头像，包含从 **16px 到 512px** 的多尺寸版本，以及 `favicon.ico`、`logo.png` 等标准图标文件。

- 涵盖尺寸：16px、32px、48px、128px、144px、180px、192px 等
- 子目录 `XJH/` 用于存放小号相关的头像及图片资源

**在线预览**：[Icon 预览画廊](https://1224huangjin.github.io/assets/images/icon/)

### 📁 `images/stickers/` — 表情包/贴图库

集中存放所有 Sticker/Meme 图片（含 GIF 动图），方便在 Discord、聊天工具等场景中快速取用——斗图、反应图、各种梗图均存放于此。

- 配套 `index.html` 页面提供动图画廊展示
- 每张图片下方可一键复制 Discord 直链

**在线预览**：[Sticker 画廊](https://1224HuangJin.github.io/assets/images/stickers/)
